# Bash-скриптинг

Bash-скрипты позволяют объединять команды в один файл и автоматически выполнять последовательность действий.

Создать файл:

```bash
nano script.sh
```

В начале скрипта обычно указывают:

```bash
#!/bin/bash
```

Запустить:

```bash
bash script.sh
```

Или сделать файл исполняемым:

```bash
chmod +x script.sh
./script.sh
```

### Условия

`if` позволяет выполнить команды только при выполнении определённого условия.

```bash
if [ "$USER" = "root" ]; then
    echo "You are root"
else
    echo "You are not root"
fi
```

Часто используются:

```bash
[ "$a" = "$b" ]    # строки равны
[ "$a" != "$b" ]   # строки не равны
[ "$a" -eq "$b" ]  # числа равны
[ "$a" -gt "$b" ]  # a больше b
[ -f file.txt ]    # файл существует
[ -d mydir ]       # каталог существует
```

### Циклы

`for` выполняет команды для каждого элемента.

```bash
for file in *.txt; do
    echo "$file"
done
```

`while` выполняет команды, пока условие истинно.

```bash
count=1

while [ $count -le 3 ]; do
    echo "$count"
    ((count++))
done
```

### Функции

Функция позволяет вынести набор команд в отдельный блок и вызывать его несколько раз.

```bash
greet() {
    echo "Hello, $1"
}

greet "Alex"
```

`$1` — первый аргумент функции.

Можно передавать несколько аргументов:

```bash
sum() {
    echo $(($1 + $2))
}

sum 5 3
```

### Exit-коды

Каждая команда после выполнения возвращает **exit-код**.

```text
0   → команда выполнена успешно
не 0 → произошла ошибка
```

Посмотреть код последней команды:

```bash
echo $?
```

Например:

```bash
ls /home
echo $?
```

Если команда выполнилась успешно, будет:

```text
0
```

В скрипте можно самостоятельно вернуть exit-код:

```bash
exit 0
```

или сообщить об ошибке:

```bash
exit 1
```

Exit-коды часто используются вместе с условиями:

```bash
if command; then
    echo "Success"
else
    echo "Error"
fi
```

Здесь Bash проверяет exit-код команды: `0` считается успехом, любой другой код — ошибкой.
