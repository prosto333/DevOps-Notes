# SSH

`SSH` (Secure Shell) позволяет безопасно подключаться к удалённому серверу и выполнять на нём команды.

```bash
ssh user@server
```

Например:

```bash
ssh alex@192.168.1.10
```

### SSH-ключи

Вместо пароля можно использовать пару SSH-ключей:

```text
private key → хранится на твоём компьютере
public key  → хранится на сервере
```

Приватный ключ **нельзя передавать другим**.

### `ssh-keygen`

Создаёт пару SSH-ключей:

```bash
ssh-keygen -t ed25519
```

Обычно ключи сохраняются в:

```text
~/.ssh/id_ed25519
~/.ssh/id_ed25519.pub
```

* `id_ed25519` — приватный ключ.
* `id_ed25519.pub` — публичный ключ.

### `ssh-copy-id`

Копирует публичный ключ на сервер:

```bash
ssh-copy-id user@server
```

После этого обычно можно подключаться без ввода пароля:

```bash
ssh user@server
```

### `~/.ssh/config`

Позволяет сохранить настройки SSH для серверов, чтобы не вводить их каждый раз.

Файл:

```bash
~/.ssh/config
```

Пример:

```text
Host myserver
    HostName 192.168.1.10
    User alex
    IdentityFile ~/.ssh/id_ed25519
```

Теперь вместо:

```bash
ssh alex@192.168.1.10
```

можно использовать:

```bash
ssh myserver
```

### Проброс портов

SSH может перенаправлять сетевые соединения через SSH-соединение.

**Локальный проброс (`-L`)** позволяет обратиться к сервису на удалённом сервере через порт своего компьютера:

```bash
ssh -L 8080:localhost:80 user@server
```

Теперь запросы к:

```text
localhost:8080
```

будут передаваться на `localhost:80` удалённого сервера.

### `scp`

`scp` копирует файлы между компьютером и сервером.

С компьютера на сервер:

```bash
scp file.txt user@server:/home/user/
```

С сервера на компьютер:

```bash
scp user@server:/home/user/file.txt .
```

Скопировать каталог:

```bash
scp -r mydir user@server:/home/user/
```

### `rsync`

`rsync` используется для синхронизации файлов и каталогов. В отличие от `scp`, он может передавать только изменившиеся данные.

```bash
rsync -av mydir/ user@server:/home/user/mydir/
```

Обратная синхронизация:

```bash
rsync -av user@server:/home/user/mydir/ ./mydir/
```

Основные параметры:

```text
-a → сохраняет структуру, права и другие атрибуты
-v → показывает, что происходит
```

### Главное

```text
ssh          → подключиться к серверу
ssh-keygen   → создать SSH-ключи
ssh-copy-id  → установить публичный ключ на сервер
~/.ssh/config → сохранить настройки подключений
ssh -L       → пробросить порт
scp          → скопировать файлы
rsync        → синхронизировать файлы
```
