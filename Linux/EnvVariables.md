# Переменные окружения

Переменные окружения — это переменные, которые хранят настройки для программ и передаются от родительского процесса к дочерним.

Например, программа может получить из окружения:

```bash
echo $USER
echo $HOME
echo $PATH
```

### Обычная переменная

Можно создать переменную прямо в текущем shell:

```bash
NAME="Alex"
```

Посмотреть её значение:

```bash
echo $NAME
```

Но дочерние процессы её не получат:

```bash
NAME="Alex"
bash
echo $NAME
```

Переменная будет недоступна в новом shell.

### `export`

`export` делает переменную **переменной окружения**, поэтому она становится доступной дочерним процессам.

```bash
export NAME="Alex"
```

Теперь:

```bash
bash
echo $NAME
```

выведет:

```text
Alex
```

То есть:

```text
NAME="Alex"          → переменная только текущего shell
export NAME="Alex"   → переменная передаётся дочерним процессам
```

### `env`

`env` показывает переменные окружения текущего процесса:

```bash
env
```

Например:

```text
HOME=/home/alex
USER=alex
PATH=/usr/local/bin:/usr/bin:/bin
```

Можно посмотреть конкретную переменную:

```bash
env | grep HOME
```

Также значение переменной можно получить через `echo`:

```bash
echo $HOME
```

### `PATH`

`PATH` — одна из самых важных переменных окружения.

Она содержит список каталогов, в которых Linux ищет исполняемые файлы команд.

```bash
echo $PATH
```

Например:

```text
/usr/local/bin:/usr/bin:/bin
```

Каталоги разделяются символом `:`.

Когда ты вводишь:

```bash
git
```

Linux ищет исполняемый файл `git` по очереди в каталогах из `PATH`.

Поэтому команду можно запускать просто:

```bash
git
```

вместо:

```bash
/usr/bin/git
```

Добавить свой каталог в `PATH`:

```bash
export PATH="$PATH:$HOME/bin"
```

Здесь:

* `$PATH` — сохраняет старое значение.
* `$HOME/bin` — добавляет новый каталог.
* `:` — разделяет каталоги.

### `.bashrc`, `.bash_profile` и `.profile`

Эти файлы используются для автоматической настройки shell.

Например, вместо того чтобы каждый раз выполнять:

```bash
export PATH="$PATH:$HOME/bin"
```

можно записать эту команду в файл настроек.

#### `.bashrc`

Используется Bash при запуске **интерактивного shell**.

Обычно сюда помещают:

```bash
alias ll='ls -la'
export PATH="$PATH:$HOME/bin"
```

То есть настройки, которые нужны при обычной работе в терминале.

#### `.bash_profile`

Используется Bash при запуске **login shell**.

Часто `.bash_profile` загружает `.bashrc`:

```bash
if [ -f ~/.bashrc ]; then
    source ~/.bashrc
fi
```

Поэтому настройки из `.bashrc` тоже применяются.

#### `.profile`

Это более общий файл настроек для **login shell**.

Он не привязан только к Bash и может использоваться другими shell.

Обычно в нём можно размещать переменные окружения:

```bash
export EDITOR=vim
export PATH="$PATH:$HOME/bin"
```

### Как это связано

Упрощённо:

```text
Login shell
    ↓
.bash_profile
    ↓
.bashrc
    ↓
настройки shell
```

А если `.bash_profile` отсутствует, Bash может использовать `.profile`.

### Применение изменений

После изменения `.bashrc` не обязательно перезапускать терминал.

Можно загрузить файл вручную:

```bash
source ~/.bashrc
```

После этого новые настройки будут доступны в текущем shell.
