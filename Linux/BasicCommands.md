# Базовые команды в терминале

1. **pwd** - показать текущую папку

1. ls - показать содержимое папки

1. ls -la  - показать все файлы включая скрытые

1. cd - перейти в папку

1. cd ..  - подняться на уровень выше

1. cd ~  - перейти в домашнюю папку

1. cd -  - вернуться в предыдущую папку

1. mkdir name - создать папку

1. touch name.txt - создать файл

1. rm file.txt - удалить файл

1. rm -r folder - удалить папку вместе с содержимым
