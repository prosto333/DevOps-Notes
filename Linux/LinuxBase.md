## Перенаправление вывода

У каждой команды в Linux есть три стандартных потока:

- `stdin (0)` — стандартный ввод.
- `stdout (1)` — стандартный вывод (обычный результат работы команды).
- `stderr (2)` — поток ошибок.

По умолчанию `stdout` и `stderr` выводятся в терминал, но их можно перенаправить в файл.

### Перенаправление stdout

```bash
man signal > man_signal
```

или явно:

```bash
man signal 1> man_signal
```

- `>` или `1>` — записывает обычный вывод (`stdout`) в файл.
- Если файл существует, его содержимое будет перезаписано.

### Перенаправление stderr

```bash
man signal 2> man_signal_error_log
```

- `2>` — записывает только сообщения об ошибках (`stderr`) в указанный файл.

### Перенаправление stdout и stderr в один файл

```bash
man signal > man_signal 2>&1
```

- `>` перенаправляет `stdout` в файл.
- `2>&1` означает: направить `stderr` туда же, куда уже направлен `stdout`.

### Конвейер (`|`)

Конвейер (`pipe`) передает результат работы одной команды на вход следующей.

```bash
ps aux | grep docker | tail -n 2
```

Здесь:
1. `ps aux` выводит список процессов.
2. `grep docker` оставляет только строки, содержащие `docker`.
3. `tail -n 2` выводит последние две строки результата.

## Команда `ls`

Команда `ls` выводит содержимое директории.

```bash
ls
```

Если путь не указан, отображается содержимое **текущей директории**.

```bash
ls /home/user
```

Выводит содержимое указанной директории.

### Полезные опции

- `-l` — подробный список файлов (права, владелец, размер, дата изменения).
- `-t` — сортировка по времени изменения (сначала новые).
- `-r` — обратный порядок сортировки.
- `-a` — показать скрытые файлы (начинаются с `.`).
- `-h` — отображать размеры файлов в удобном формате (`K`, `M`, `G`).

Опции можно комбинировать:

```bash
ls -ltrh
```

- `-l` — подробный вывод.
- `-t` — сортировка по времени.
- `-r` — обратный порядок.
- `-h` — удобочитаемые размеры.

### Специальные директории

- `.` — текущая директория.
- `..` — родительская директория.

Примеры:

```bash
ls .
```

Показать содержимое текущей директории.

```bash
ls ..
```

Показать содержимое родительской директории.

```bash
ls ../home/user
```

Показать содержимое указанной директории относительно текущего расположения.

## cd

Изменить текущую директорию.

    [user@testhost ~]$ pwd
    /home/user
    [user@testhost ~]$ cd /home/
    [user@testhost home]$ pwd
    /home


Если не передавать имя директории в качестве аргумента, будет использоваться переменная окружения $HOME, то есть домашняя директория. Также может быть удобно использовать `~` — специальный символ, означающий $HOME:

    [user@testhost etc]$ pwd
    /etc
    [user@testhost etc]$ cd ~/test/
    [user@testhost test]$ pwd
    /home/user/test

## mkdir

Создать директорию.

    [user@testhost ~]$ mkdir test
    [user@testhost ~]$ ls -ltr
    total 38184
    -rw-rw-r-- 1 user user 39091284 Nov 22 14:14 qqq
    drwxrwxr-x 2 user user     4096 Nov 26 10:29 test


Иногда нужно создать определенную структуру директорий: например, директорию в директории, которой не существует. Чтобы не вводить несколько раз подряд mkdir, можно использовать опцию -p — она позволяет создать все недостающие директории в иерархии. Также с этой опцией mkdir не вернет ошибку, если директория существует.

    [user@testhost ~]$ ls
    qqq  test
    [user@testhost ~]$ mkdir test2/subtest
    mkdir: cannot create directory ‘test2/subtest’: No such file or directory
    [user@testhost ~]$ mkdir -p test2/subtest
    [user@testhost ~]$ ls
    qqq  test  test2
    [user@testhost ~]$ ls test2/
    subtest
    [user@testhost ~]$ mkdir test2/subtest
    mkdir: cannot create directory ‘test2/subtest’: File exists
    [user@testhost ~]$ mkdir -p test2/subtest
    [user@testhost ~]$ ls test2/
    subtest

## rm

Удалить файл.

    [user@testhost ~]$ ls
    qqq  test  test2
    [user@testhost ~]$ rm qqq
    [user@testhost ~]$ ls
    test  test2


Опция -r позволяет рекурсивно удалять директории со всем их содержимым, опция -f позволяет игнорировать ошибки при удалении (например, о несуществующем файле). Эти опции позволяют, грубо говоря, гарантированно удалить всю иерархию файлов и директорий (если на это есть права у пользователя), поэтому, их нужно использовать с осторожностью (классический пример-шутка — "rm -rf /", при определенных обстоятельствах удалит вам если не всю систему, то очень много важных для её работоспособности файлов).

    [user@testhost ~]$ ls
    test  test2
    [user@testhost ~]$ ls -ltr test2/
    total 4
    -rw-rw-r-- 1 user user    0 Nov 26 10:40 temp
    drwxrwxr-x 2 user user 4096 Nov 26 10:40 temp_dir
    [user@testhost ~]$ rm -rf test2
    [user@testhost ~]$ ls
    test

## cp

Копировать файл или директорию.

    [user@testhost ~]$ ls
    temp  test
    [user@testhost ~]$ cp temp temp_clone
    [user@testhost ~]$ ls
    temp  temp_clone  test


У этой команды также есть опции -r и -f, их можно использовать, чтобы гарантированно скопировать иерархию директорий и папок в другое место.

## mv

Переместить или переименовать файл или директорию.

    [user@testhost ~]$ ls -ltr
    total 4
    drwxrwxr-x 2 user user 4096 Nov 26 10:29 test
    -rw-rw-r-- 1 user user    0 Nov 26 10:45 temp
    -rw-rw-r-- 1 user user    0 Nov 26 10:46 temp_clone
    [user@testhost ~]$ ls test
    [user@testhost ~]$ mv test test_renamed
    [user@testhost ~]$ mv temp_clone test_renamed/
    [user@testhost ~]$ ls
    temp  test_renamed
    [user@testhost ~]$ ls test_renamed/
    temp_clone

## cat

Вывести содержимое файла (или файлов).

    [user@testhost ~]$ cat temp
    Content of a file.
    Lalalala...


Также стоит обратить внимание на команды head (вывести n первых строк или байт файла) и tail (о ней — далее).


## tail

Вывести n последних строк или байт файла.

    [user@testhost ~]$ tail -1 temp
    Lalalala...


Очень полезной является опция -f — она позволяет выводить новые данные в файле в реальном времени.

## less

Иногда текстовый файл слишком большой, и неудобно выводить его командой cat. Тогда можно открыть его с помощью команды less: файл будет выводиться по частям, доступна навигация по этим частям, поиск и прочий простой функционал.

    [user@testhost ~]$ less temp


Также может оказаться удобным вариант использования less с конвейером (pipe):

    [user@testhost ~]$ grep "ERROR" /tmp/some.log | less


## ps

Команда `ps` отображает список запущенных процессов.

```bash
ps
```

По умолчанию показывает процессы, запущенные в текущем терминале.

### Полезные опции

#### Показать все процессы

```bash
ps aux
```

Наиболее часто используемый вариант.

- `a` — процессы всех пользователей.
- `u` — подробная информация (пользователь, CPU, память и др.).
- `x` — процессы без привязки к терминалу (например, системные службы).

Обычно результат фильтруют через `grep`:

```bash
ps aux | grep nginx
```

#### Показать дерево процессов

```bash
ps axjf
```

Отображает процессы в виде дерева, показывая родительские и дочерние процессы. Удобно для анализа того, какой процесс запустил другой.

### Когда использовать

- посмотреть список запущенных процессов;
- найти нужный процесс по имени (`ps aux | grep <имя>`);
- определить `PID` процесса для его завершения (`kill`);
- посмотреть иерархию процессов (`ps axjf`).

## kill

Послать сигнал процессу. По умолчанию посылается сигнал SIGTERM, который завершает процесс.

    [user@testhost ~]$ ps ux
    USER         PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
    531      1027147  0.0  0.0 119956  4260 ?        S    14:51   0:00 sshd: user@pts/1
    531      1027149  0.0  0.0 115408  3396 pts/1    Ss   14:51   0:00 -bash
    531      1027170  0.0  0.0 119956  4136 ?        R    14:51   0:00 sshd: user@pts/2
    531      1027180  0.0  0.0 115408  3564 pts/2    Ss   14:51   0:00 -bash
    531      1033727  0.0  0.0 107960   708 pts/1    S+   15:17   0:00 sleep 300
    531      1033752  0.0  0.0 117264  2604 pts/2    R+   15:17   0:00 ps ux
    [user@testhost ~]$ kill 1033727
    [user@testhost ~]$ ps ux
    USER         PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
    531      1027147  0.0  0.0 119956  4260 ?        S    14:51   0:00 sshd: user@pts/1
    531      1027149  0.0  0.0 115408  3396 pts/1    Ss+  14:51   0:00 -bash
    531      1027170  0.0  0.0 119956  4136 ?        R    14:51   0:00 sshd: user@pts/2
    531      1027180  0.0  0.0 115408  3564 pts/2    Ss   14:51   0:00 -bash
    531      1033808  0.0  0.0 117268  2492 pts/2    R+   15:17   0:00 ps ux


Так как процесс может иметь обработчики сигналов, kill не всегда приводит к ожидаемому результату — моментальному завершению процесса. Чтобы «убить» процесс наверняка, нужно послать процессу сигнал SIGKILL. Однако это может привести к потере данных (например, если процесс перед завершением должен сохранить какую-то информацию на диск), так что нужно пользоваться такой командой осторожно. Номер сигнала SIGKILL — 9, поэтому короткий вариант команды выглядит так:

    [user@testhost ~]$ ps ux | grep sleep
    531      1034930  0.0  0.0 107960   636 pts/1    S+   15:21   0:00 sleep 300
    531      1034953  0.0  0.0 110516  2104 pts/2    S+   15:21   0:00 grep --color=auto sleep
    [user@testhost ~]$ kill -9 1034930
    [user@testhost ~]$ ps ux | grep sleep
    531      1035004  0.0  0.0 110516  2092 pts/2    S+   15:22   0:00 grep --color=auto sleep


Помимо упомянутых SIGTERM и SIGKILL существует еще множество различных сигналов, их список можно легко найти в интернете. И не забывайте, что сигналы SIGKILL и SIGSTOP не могут быть перехвачены или проигнорированы.

## Команда `ping`

Команда `ping` проверяет доступность удаленного хоста и измеряет время отклика сети с помощью ICMP-пакетов.

```bash
ping google.com
```

По умолчанию команда отправляет пакеты **непрерывно**, пока ее не остановить (`Ctrl + C`).

### Полезные опции

#### Ограничить количество пакетов

```bash
ping -c 3 google.com
```

- `-c` — отправить указанное количество пакетов и завершить команду.

#### Установить интервал между пакетами

```bash
ping -i 5 google.com
```

- `-i` — интервал между отправкой пакетов (в секундах).

Можно комбинировать опции:

```bash
ping -c 3 -i 5 google.com
```

### Как читать результат

- `time` — время ответа (задержка). Чем меньше, тем лучше.
- `packet loss` — процент потерянных пакетов. В идеале — `0%`.
- `rtt min/avg/max` — минимальное, среднее и максимальное время отклика.

### Когда использовать

- проверить доступность сервера или сайта;
- проверить, работает ли сеть;
- измерить задержку соединения;
- обнаружить потерю пакетов.


## Команда `ssh`

`ssh` (Secure Shell) — программа для **безопасного удаленного подключения** к другому компьютеру или серверу через сеть.

### Подключение к серверу

```bash
ssh user@192.168.1.10
```

или

```bash
ssh user@example.com
```

- `user` — имя пользователя на удаленном сервере.
- `192.168.1.10` или `example.com` — IP-адрес или доменное имя сервера.

После подключения вы работаете в терминале **удаленного компьютера**, как будто находитесь за ним.

### Что происходит при первом подключении

При первом подключении SSH попросит подтвердить отпечаток (fingerprint) сервера:

```text
Are you sure you want to continue connecting (yes/no)?
```

Введите `yes`, после чего ключ сервера будет сохранен, и в дальнейшем этот вопрос не появится.

### Аутентификация

SSH поддерживает два основных способа входа:

- **по паролю** — вводится пароль пользователя;
- **по SSH-ключу** — более безопасный и распространенный способ, особенно на серверах.

### Где используется SSH

- удаленное администрирование Linux-серверов;
- работа с облачными серверами (AWS, DigitalOcean, Hetzner и др.);
- выполнение команд без физического доступа к компьютеру;
- передача файлов (`scp`, `sftp`).

> **Важно:** SSH шифрует весь передаваемый трафик, поэтому соединение защищено от перехвата.


## Команда `scp`

`scp` (Secure Copy) — утилита для **безопасного копирования файлов** между локальным компьютером и удаленным сервером через SSH.

### Скопировать файл с удаленного сервера

```bash
scp user@192.168.1.10:/home/user/file.txt ./
```

- `user@192.168.1.10` — пользователь и адрес сервера.
- `/home/user/file.txt` — путь к файлу на сервере.
- `./` — директория на локальном компьютере, куда будет сохранен файл.

### Скопировать файл на удаленный сервер

```bash
scp file.txt user@192.168.1.10:/home/user/
```

Файл `file.txt` будет скопирован с локального компьютера на сервер.

### Копирование директорий

```bash
scp -r project/ user@192.168.1.10:/home/user/
```

- `-r` — рекурсивное копирование директорий.

### Когда использовать

- скачать файл с сервера;
- загрузить файл на сервер;
- скопировать папку между локальным компьютером и удаленным сервером.

> `scp` использует SSH, поэтому все данные передаются в зашифрованном виде.

## Команда `rsync`

`rsync` — утилита для **синхронизации файлов и директорий** между локальным компьютером и удаленным сервером. Работает поверх SSH и копирует только измененные файлы, что делает ее быстрее и эффективнее `scp`.

### Скопировать директорию с сервера

```bash
rsync -av user@192.168.1.10:/home/user/ Downloads/
```

### Скопировать директорию на сервер

```bash
rsync -av project/ user@192.168.1.10:/home/user/project/
```

### Полезные опции

- `-a` (`archive`) — копирует директорию целиком, сохраняя структуру, права доступа, владельцев и время изменения файлов.
- `-v` (`verbose`) — выводит подробную информацию о процессе копирования.

### Преимущества `rsync`

- копирует **только новые или измененные файлы**;
- подходит для резервного копирования и синхронизации;
- может продолжить копирование после прерывания;
- работает через SSH, поэтому передача данных защищена.

### Когда использовать

- синхронизация локальной и удаленной директорий;
- резервное копирование;
- перенос больших проектов на сервер.

## Команда `echo`

Команда `echo` выводит текст или значение переменной в терминал.

### Вывести текст

```bash
echo "Hello"
```

### Полезные опции

#### `-n` — без переноса строки

```bash
echo -n "Hello"
```

По умолчанию `echo` добавляет перевод строки (`\n`) в конце вывода. Опция `-n` отключает это поведение.

#### `-e` — интерпретация специальных символов

```bash
echo -e "\tHello\nWorld"
```

Наиболее используемые управляющие последовательности:

- `\n` — новая строка.
- `\t` — табуляция.
- `\\` — символ обратной косой черты (`\`).

### Вывод значений переменных

```bash
echo $HOME
```

Выведет значение переменной окружения `HOME`.

### Код завершения последней команды

```bash
echo $?
```

Переменная `$?` содержит код завершения последней выполненной команды.

- `0` — команда выполнена успешно.
- Любое другое значение — произошла ошибка.

Пример:

```bash
ls
echo $?    # 0

ls unknown
echo $?    # ненулевой код ошибки
```

### Когда использовать

- вывести текст в терминал;
- проверить значение переменной;
- узнать, успешно ли выполнилась предыдущая команда (`echo $?`).

## Команда `telnet`

`telnet` — клиент для подключения к удаленному хосту по указанному порту. Сегодня чаще используется **не для протокола Telnet**, а для проверки доступности TCP-портов и ручного взаимодействия с простыми текстовыми протоколами (например, HTTP).

### Подключение к хосту

```bash
telnet example.com 80
```

- `example.com` — адрес сервера.
- `80` — порт, к которому выполняется подключение.

Если соединение успешно, можно вручную отправлять команды. Например, HTTP-запрос:

```text
GET / HTTP/1.1
Host: example.com

```

После пустой строки сервер вернет HTTP-ответ.

### Когда использовать

- проверить, открыт ли TCP-порт;
- убедиться, что сервис принимает подключения;
- вручную протестировать текстовые сетевые протоколы (HTTP, SMTP и др.).

> **Важно:** `telnet` **не поддерживает шифрование (TLS/SSL)**. Для работы с защищенными соединениями (например, HTTPS на порту 443) используют `openssl s_client` или другие современные инструменты (`curl`, `nc`).

# Решение типовых задач в Linux

## Изменение владельца файла

Чтобы изменить владельца файла или папки, используется команда `chown`.

### Синтаксис

```bash
chown новый_владелец:группа файл
```

### Пример

```bash
[user@testhost ~]$ chown user:user temp
[user@testhost ~]$ ls -l temp
-rw-rw-r-- 1 user user 31 Nov 26 11:09 temp
```

### Объяснение

* `user:user`

  * первый `user` — новый **владелец** файла;
  * второй `user` — **группа**, которой будет принадлежать файл.
* `temp` — файл, для которого меняются владелец и группа.

После выполнения команды можно проверить изменения командой:

```bash
ls -l temp
```

В первой части вывода будут отображаться права доступа, а затем — владелец и группа.

### Изменение владельца папки вместе со всем содержимым

Если нужно изменить владельца не только папки, но и всех файлов внутри неё, используется параметр `-R` (Recursive — рекурсивно).

```bash
chown -R user:user my_folder
```

После выполнения команды владельцы изменятся у папки и у всех вложенных файлов и каталогов.

---

## Изменение прав доступа к файлу

Для изменения прав доступа используется команда `chmod`.

### Пример

Сначала посмотрим текущие права:

```bash
[user@testhost ~]$ ls -l temp
-rw-rw-r-- 1 user user 31 Nov 26 11:09 temp
```

Теперь изменим права:

```bash
[user@testhost ~]$ chmod 760 temp
[user@testhost ~]$ ls -l temp
-rwxrw---- 1 user user 31 Nov 26 11:09 temp
```

### Что означает число `760`

Каждая цифра отвечает за права определённой категории пользователей:

* первая — **владелец**;
* вторая — **группа**;
* третья — **остальные пользователи**.

В нашем примере:

* `7` — владелец может:

  * читать (`r`);
  * записывать (`w`);
  * выполнять (`x`).

* `6` — группа может:

  * читать (`r`);
  * записывать (`w`).

* `0` — остальные пользователи не имеют никаких прав.

### Как формируются числа

Каждое разрешение имеет своё значение:

| Право      | Символ | Значение |
| ---------- | ------ | -------- |
| Чтение     | `r`    | 4        |
| Запись     | `w`    | 2        |
| Выполнение | `x`    | 1        |

Число получается сложением этих значений.

Например:

| Число | Права | Объяснение    |
| ----- | ----- | ------------- |
| 7     | `rwx` | 4 + 2 + 1 = 7 |
| 6     | `rw-` | 4 + 2 = 6     |
| 5     | `r-x` | 4 + 1 = 5     |
| 4     | `r--` | только чтение |
| 0     | `---` | нет прав      |

Поэтому запись

```bash
chmod 760 temp
```

означает:

* владелец — `rwx`;
* группа — `rw-`;
* остальные — `---`.

---

## Изменение прав с помощью символов

Кроме чисел, `chmod` поддерживает символьный способ изменения прав.

Например, сначала уберём право на выполнение файла, а затем вернём его обратно.

```bash
[user@testhost ~]$ ls -l temp
-rwxrw---- 1 user user 31 Nov 26 11:09 temp

[user@testhost ~]$ chmod -x temp

[user@testhost ~]$ ls -l temp
-rw-rw---- 1 user user 31 Nov 26 11:09 temp

[user@testhost ~]$ chmod +x temp

[user@testhost ~]$ ls -l temp
-rwxrwx--x 1 user user 31 Nov 26 11:09 temp
```

### Что делают команды

```bash
chmod -x temp
```

Удаляет право на выполнение (`x`).

```bash
chmod +x temp
```

Добавляет право на выполнение.

Такой способ удобен, когда не хочется пересчитывать числовые значения прав.

### Полезные символы

| Команда         | Что делает          |
| --------------- | ------------------- |
| `chmod +x file` | добавить выполнение |
| `chmod -x file` | убрать выполнение   |
| `chmod +r file` | добавить чтение     |
| `chmod -r file` | убрать чтение       |
| `chmod +w file` | добавить запись     |
| `chmod -w file` | убрать запись       |

---

## Итог

В Linux чаще всего используются две команды для работы с файлами:

* `chown` — изменяет владельца и группу файла или каталога;
* `chmod` — изменяет права доступа.

Для `chmod` можно использовать два способа:

* **числовой** (`755`, `760`, `644`);
* **символьный** (`+x`, `-w`, `u+r` — добавить право чтения для владельца (user), `g-x` — убрать право выполнения у группы и т.д.).

Числовой способ обычно применяют при настройке прав сразу, а символьный — когда нужно быстро добавить или убрать конкретное разрешение.


## Просмотр содержимого бинарного файла

Для просмотра содержимого бинарных файлов используется утилита `hexdump`.

Она позволяет вывести данные файла в шестнадцатеричном (HEX) виде или показать, какие байты хранятся внутри файла.

## Для чего используется

Команда `hexdump` может пригодиться в следующих случаях:

* просмотр содержимого бинарных файлов, которые невозможно открыть обычным текстовым редактором;
* анализ исполняемых файлов (`.exe`, ELF), изображений, архивов и других бинарных данных;
* поиск ошибок при разработке программ;
* проверка структуры файлов и заголовков (например, определить настоящий тип файла);
* анализ данных при изучении операционных систем и информационной безопасности.

---

## Просмотр файла как текста (`-c`)

Пусть имеется файл:

```bash
[user@testhost ~]$ cat temp
Content of a file.
Lalalala...
```

Выведем его содержимое с помощью `hexdump`:

```bash
[user@testhost ~]$ hexdump -c temp
0000000   C   o   n   t   e   n   t       o   f       a       f   i   l
0000010   e   .  \n   L   a   l   a   l   a   l   a   .   .   .  \n
000001f
```

### Объяснение

Опция `-c` отображает каждый байт как символ ASCII.

Также показываются специальные символы:

* `\n` — переход на новую строку;
* `\t` — табуляция (если присутствует);
* остальные непечатаемые символы также отображаются специальными обозначениями.

Такой режим удобен, если нужно увидеть текст и управляющие символы одновременно.

---

## Просмотр файла в шестнадцатеричном виде (`-x`)

```bash
[user@testhost ~]$ hexdump -x temp
0000000    6f43    746e    6e65    2074    666f    6120    6620    6c69
0000010    2e65    4c0a    6c61    6c61    6c61    2e61    2e2e    000a
000001f
```

### Объяснение

Опция `-x` выводит содержимое файла в шестнадцатеричном формате (HEX).

Каждое число представляет собой значение нескольких байтов.

Такой формат часто используют программисты, системные администраторы и специалисты по информационной безопасности при анализе структуры файлов.

---

## Канонический HEX-вывод (`-C`)

```bash
[user@testhost ~]$ hexdump -C temp
00000000  43 6f 6e 74 65 6e 74 20  6f 66 20 61 20 66 69 6c  |Content of a fil|
00000010  65 2e 0a 4c 61 6c 61 6c  61 6c 61 2e 2e 2e 0a     |e..Lalalala....|
0000001f
```

### Объяснение

Опция `-C` считается самой удобной, потому что показывает сразу три части:

* **смещение (Offset)** — адрес начала строки относительно начала файла;
* **HEX-представление** — значения байтов в шестнадцатеричном формате;
* **ASCII-представление** — символы, соответствующие этим байтам.

Например:

```text
00000000  43 6f 6e 74 ... |Content...|
```

Здесь:

* `00000000` — начало файла;
* `43 6f 6e 74 ...` — байты в формате HEX;
* `|Content...|` — те же данные, но в виде обычного текста.

Именно этот режим чаще всего используется при анализе файлов, так как позволяет одновременно видеть и байты, и их текстовое представление.

---

## Итог

Наиболее полезные варианты использования `hexdump`:

| Команда           | Назначение                                          |
| ----------------- | --------------------------------------------------- |
| `hexdump -c file` | показать содержимое как символы ASCII               |
| `hexdump -x file` | вывести данные в шестнадцатеричном формате          |
| `hexdump -C file` | показать одновременно HEX и текстовое представление |

В большинстве случаев для анализа бинарных файлов рекомендуется использовать именно `hexdump -C`, так как этот режим наиболее информативен и удобен для чтения.

## Поиск файлов

Для поиска файлов и папок в Linux используется команда `find`.

## Для чего используется

`find` помогает:

* найти файл по имени или его части;
* искать файлы по типу, размеру, дате создания или изменения;
* быстро находить нужные файлы в больших каталогах.

---

## Поиск по части имени

```bash
[user@testhost ~]$ find test_dir/ -name "*le*"
test_dir/file_1
test_dir/file_2
test_dir/subdir/file_3
```

### Объяснение

* `test_dir/` — каталог, в котором выполняется поиск;
* `-name` — поиск по имени;
* `"*le*"` — шаблон, где `*` означает любое количество символов. Будут найдены все файлы, содержащие `le` в имени.

---

## Поиск файлов по времени создания

Например, найти обычные файлы, созданные более 5 дней назад:

```bash
[user@testhost ~]$ ls -ltr test
total 0
-rw-rw-r-- 1 user user 0 Nov 26 10:46 temp_clone
-rw-rw-r-- 1 user user 0 Dec  4 10:39 created_today

[user@testhost ~]$ find test/ -type f -ctime +5
test/temp_clone
```

### Объяснение

* `-type f` — искать только обычные файлы;
* `-ctime +5` — файлы, созданные (или с изменёнными метаданными) более 5 дней назад.

## Итог

Наиболее часто используемые параметры:

| Команда                  | Назначение             |
| ------------------------ | ---------------------- |
| `find dir -name "*.txt"` | поиск файлов по имени  |
| `find dir -type f`       | поиск только файлов    |
| `find dir -type d`       | поиск только каталогов |
| `find dir -ctime +5`     | файлы старше 5 дней    |

# Поиск текста в файлах

Для поиска текста внутри файлов используется команда `grep`.

## Для чего используется

`grep` помогает:

* найти слово или фразу в одном или нескольких файлах;
* искать ошибки в логах;
* фильтровать вывод других команд.

---

## Поиск текста в файлах

```bash
[user@testhost ~]$ grep -nr "content" test_dir/
test_dir/file_1:1:test content for file_1
test_dir/file_2:1:test content for file_2
test_dir/subdir/file_3:1:test content for file_3
```

### Объяснение

* `-n` — показать номер строки;
* `-r` — искать рекурсивно во всех вложенных каталогах;
* `"content"` — искомый текст;
* `test_dir/` — каталог, в котором выполняется поиск.

---

## Использование в конвейере (Pipe)

`grep` часто используют вместе с другими командами через символ `|`, чтобы отфильтровать их вывод.

Например, вывести только строки с ошибками из файла журнала:

```bash
[user@testhost ~]$ sudo tail -f /var/log/test.log | grep "ERROR"
```

### Объяснение

* `tail -f` — непрерывно показывает новые строки файла;
* `|` — передаёт вывод одной команды другой;
* `grep "ERROR"` — оставляет только строки, содержащие `ERROR`.

Такой способ часто используют для мониторинга логов в реальном времени.

---

## Обратный поиск

Опция `-v` выводит строки, **не содержащие** указанный текст.

```bash
grep -v "ERROR" test.log
```

Эта команда покажет все строки файла `test.log`, кроме тех, где встречается `ERROR`.

## Итог

| Команда                  | Назначение                           |
| ------------------------ | ------------------------------------ |
| `grep "text" file`       | поиск текста в файле                 |
| `grep -r "text" dir`     | поиск во всех файлах каталога        |
| `grep -n "text" file`    | показать номера строк                |
| `grep -v "text" file`    | исключить строки с указанным текстом |
| `команда \| grep "text"` | фильтрация вывода другой команды     |

## Для чего используется

Просмотр списка пакетов помогает:

* узнать, установлена ли нужная программа;
* проверить версию установленного пакета;
* найти название пакета перед обновлением или удалением;

## Итог

Если вы не знаете, какая система установлена, сначала определите дистрибутив Linux, а затем используйте соответствующую команду для просмотра списка установленных пакетов.

# Просмотр размера директорий

Для оценки размера папок используется команда `du` (Disk Usage).

## Для чего используется

`du` помогает:

* узнать, сколько места занимает папка;
* найти каталоги, занимающие больше всего места;
* определить, что можно удалить для освобождения дискового пространства.

---

## Просмотр размера дерева директорий

```bash
[user@testhost ~]$ du -h -d 1 test_dir/
8,0K test_dir/subdir
20K test_dir/
```

### Объяснение

* `-h` — вывод размера в удобном формате (`K`, `M`, `G`);
* `-d 1` — показать размер только текущего каталога и его непосредственных подкаталогов;
* `test_dir/` — каталог, для которого вычисляется размер.

При увеличении значения `-d` отображается информация о более глубоких уровнях вложенности.

---

## Сортировка по размеру

По возрастанию:

```bash
[user@testhost ~]$ du -h -d 1 test_dir/ | sort -h
8,0K test_dir/subdir
16K test_dir/subdir_2
36K test_dir/
```

По убыванию:

```bash
[user@testhost ~]$ du -h -d 1 test_dir/ | sort -h -r
36K test_dir/
16K test_dir/subdir_2
8,0K test_dir/subdir
```

### Объяснение

* `sort -h` — сортирует размеры с учётом единиц измерения (`K`, `M`, `G`);
* `-r` — выполняет сортировку в обратном порядке (от большего к меньшему).

Такой способ удобен для быстрого поиска каталогов, занимающих больше всего места.

## Итог

| Команда                        | Назначение                         |
| ------------------------------ | ---------------------------------- |
| `du -h dir`                    | размер каталога                    |
| `du -h -d 1 dir`               | размер каталога и его подкаталогов |
| `du -h -d 1 dir \| sort -h`    | сортировка по возрастанию          |
| `du -h -d 1 dir \| sort -h -r` | сортировка по убыванию             |


# Поиск и замена текста в файлах

Для поиска и замены текста используется утилита `sed` (Stream Editor).

## Для чего используется

`sed` помогает:

* заменить текст в одном или нескольких файлах;
* быстро изменить конфигурационные файлы;
* автоматически редактировать большое количество файлов.

---

## Замена текста в файле

```bash
sed -i 's/old-text/new-text/g' input.txt
```

### Объяснение

* `-i` — изменить файл без создания нового;
* `s` — операция замены (*substitute*);
* `old-text` — текст, который нужно найти;
* `new-text` — текст, на который производится замена;
* `g` — заменить **все** вхождения в каждой строке. Без `g` заменится только первое совпадение.

---

## Замена текста в нескольких файлах

```bash
[user@testhost ~]$ cat test_dir/file_*
test content for file_1
test content for file_2

[user@testhost ~]$ sed -i 's/test/edited/g' test_dir/file_*

[user@testhost ~]$ cat test_dir/file_*
edited content for file_1
edited content for file_2
```

### Объяснение

Команда изменяет все файлы, подходящие под шаблон `file_*`, заменяя каждое слово `test` на `edited`.

## Итог

| Команда                       | Назначение                                                |
| ----------------------------- | --------------------------------------------------------- |
| `sed 's/a/b/' file`           | заменить первое совпадение в строке (без изменения файла) |
| `sed -i 's/a/b/g' file`       | заменить все совпадения в файле                           |
| `sed -i 's/a/b/g' dir/file_*` | заменить текст сразу в нескольких файлах                  |


# Вывод определённой колонки

Для извлечения отдельных столбцов из вывода команд используется утилита `awk`.

## Для чего используется

`awk` помогает:

* вывести нужную колонку из таблицы;
* фильтровать и обрабатывать текст;
* создавать простые отчёты и автоматизировать работу с данными.

---

## Вывод колонки

Например, вывести идентификаторы процессов (PID) из вывода команды `ps ux`:

```bash
[user@testhost ~]$ ps ux | awk '{print $2}'
PID
11023
25870
25871
25908
25909
```

### Объяснение

* `ps ux` — выводит список запущенных процессов;
* `|` — передаёт вывод команды в `awk`;
* `'{print $2}'` — выводит **вторую колонку** (`$1` — первая, `$2` — вторая и т.д.).

В данном случае второй столбец содержит идентификаторы процессов (PID).

## Итог

| Команда                       | Назначение                                       |
| ----------------------------- | ------------------------------------------------ |
| `awk '{print $1}'`            | вывести первую колонку                           |
| `awk '{print $2}'`            | вывести вторую колонку                           |
| `команда \| awk '{print $N}'` | вывести N-ю колонку из результата другой команды |

> **Примечание:** `awk` — мощный инструмент для обработки текста. Помимо вывода отдельных колонок, он позволяет выполнять фильтрацию, вычисления, форматирование и обработку данных прямо в командной строке.


# Определение IP-адреса по имени хоста

Чтобы узнать IP-адрес доменного имени, можно использовать команды `host`, `dig` или `nslookup`.

## Для чего используется

Эти команды помогают:

* узнать IP-адрес сайта или сервера;
* проверить работу DNS;
* диагностировать сетевые проблемы;
* проверить, на какой сервер указывает доменное имя.

---

## Использование `host`

```bash id="7slnc5"
[user@testhost ~]$ host ya.ru
ya.ru has address 87.250.250.242
ya.ru has IPv6 address 2a02:6b8::2:242
ya.ru mail is handled by 10 mx.yandex.ru.
```

### Объяснение

Команда показывает:

* IPv4-адрес (`87.250.250.242`);
* IPv6-адрес (если есть);
* информацию о почтовом сервере (MX-запись).

---

## Использование `dig`

```bash id="m70pgf"
[user@testhost ~]$ dig +short ya.ru
87.250.250.242
```

### Объяснение

Опция `+short` выводит только IP-адрес без дополнительной информации. Это удобно при использовании в скриптах.

---

## Использование `nslookup`

```bash id="8ptlgn"
[user@testhost ~]$ nslookup ya.ru
Server: 8.8.8.8
Address: 8.8.8.8#53

Non-authoritative answer:
Name: ya.ru
Address: 87.250.250.242
```

### Объяснение

`nslookup` показывает DNS-сервер, который выполнил запрос, и найденный IP-адрес домена.

## Итог

| Команда                  | Назначение                           |
| ------------------------ | ------------------------------------ |
| `host example.com`       | подробная информация о домене        |
| `dig +short example.com` | вывести только IP-адрес              |
| `nslookup example.com`   | проверить разрешение имени через DNS |


# Сетевая информация

## Просмотр интерфейсов через `ifconfig`

> `ifconfig` считается устаревшей утилитой, но до сих пор встречается во многих системах.

```bash
ifconfig
```

Пример вывода:

```text
eth0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 1500
    inet 47.89.93.67  netmask 255.255.224.0  broadcast 47.89.95.255
    inet6 fd90::302:57ff:fe79:1  prefixlen 64
    ether 04:01:57:79:00:01
```

### Основные поля

* **eth0** — имя сетевого интерфейса.
* **UP** — интерфейс включён.
* **RUNNING** — интерфейс активен и работает.
* **mtu 1500** — максимальный размер передаваемого пакета.
* **inet** — IPv4-адрес.
* **netmask** — маска подсети.
* **broadcast** — широковещательный адрес.
* **inet6** — IPv6-адрес.
* **ether** — MAC-адрес интерфейса.

Интерфейс **lo** — это локальный (Loopback) интерфейс с адресом `127.0.0.1`, который используется для связи компьютера с самим собой.

---

## Просмотр интерфейсов через `ip`

Современная альтернатива `ifconfig` — команда `ip`.

```bash
ip a
```

Пример вывода:

```text
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 47.89.93.67/19 brd 47.89.95.255 scope global eth0
    inet6 fd90::302:57ff:fe79:1/64 scope link
```

### Основные поля

* **eth0** — имя интерфейса.
* **UP** — интерфейс включён.
* **LOWER_UP** — физическое соединение активно.
* **mtu 1500** — максимальный размер пакета.
* **inet** — IPv4-адрес с префиксом сети (`/19`).
* **brd** — широковещательный адрес.
* **scope global** — адрес доступен в сети.
* **inet6** — IPv6-адрес.

---

## Показать только IPv4

Если нужны только IPv4-адреса:

```bash
ip -4 a
```

Вывод будет содержать только строки с адресами IPv4, что удобно при поиске IP-адреса сервера.


# Просмотр открытых портов

Для просмотра открытых (слушающих) TCP- и UDP-портов можно использовать команду:

```bash
netstat -lptnu
```

### Что означают параметры

* **-l** — показать только слушающие порты.
* **-p** — вывести PID и имя процесса, использующего порт.
* **-t** — показать TCP-порты.
* **-u** — показать UDP-порты.
* **-n** — не преобразовывать адреса и порты в имена (быстрее и удобнее для анализа).

> **Примечание:** `netstat` считается устаревшей утилитой. В современных дистрибутивах Linux рекомендуется использовать `ss`, который работает быстрее и предоставляет аналогичную информацию.

Эквивалентная команда:

```bash
ss -lptnu
```

# Информация о памяти

Для просмотра информации об использовании оперативной памяти и раздела подкачки (Swap) используется команда:

```bash
free -h
```

Пример вывода:

```text
              total        used        free      shared  buff/cache   available
Mem:           3.9G        555M        143M         56M        3.2G        3.0G
Swap:            0B          0B          0B
```

### Основные поля

| Поле           | Описание                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------- |
| **total**      | Общий объем оперативной памяти.                                                               |
| **used**       | Используемая память.                                                                          |
| **free**       | Полностью свободная память.                                                                   |
| **shared**     | Память, используемая несколькими процессами.                                                  |
| **buff/cache** | Память, занятая буферами и файловым кэшем. При необходимости она освобождается автоматически. |
| **available**  | Объем памяти, доступный для запуска новых приложений без использования Swap.                  |

### Swap

Строка **Swap** показывает использование раздела (или файла) подкачки:

* **total** — общий размер Swap.
* **used** — используемый объем.
* **free** — свободный объем.

> **Примечание:** В современных Linux ориентируйтесь в первую очередь на столбец **available**, а не **free**. Небольшое значение `free` — это нормально, так как Linux активно использует свободную память для кэширования данных.



# Информация о файловых системах

Для просмотра использования дискового пространства на примонтированных файловых системах используется команда:

```bash
df -hT
```

### Основные поля

| Поле                 | Описание                                             |
| -------------------- | ---------------------------------------------------- |
| **Файловая система** | Устройство или файловая система.                     |
| **Тип**              | Тип файловой системы (`ext4`, `xfs`, `tmpfs` и др.). |
| **Размер**           | Общий размер файловой системы.                       |

### Полезные параметры

| -------- | ------------------------------------------------ |

> **Примечание:** `tmpfs` и `devtmpfs` — это временные файловые системы, размещаемые в оперативной памяти. Они не занимают место на диске и используются системой для хранения временных данных и информации об устройствах.



# Информация о процессах и состоянии системы

Для мониторинга процессов и ресурсов системы используется команда:

```bash id="eh2nqk"
top
```

Чтобы вывести только первые строки (например, для отчета или скрипта):

```bash id="r5w2j8"
top | head -10
```

Пример вывода:

```text id="z8f6dn"
top - 17:19:13 up 154 days, 6:59, 3 users, load average: 0.21, 0.21, 0.27
Tasks: 2169 total, 2 running, 2080 sleeping, 0 stopped, 0 zombie
Cpu(s): 1.7%us, 0.7%sy, 97.5%id
Mem: 125889960k total, 82423048k used, 43466912k free
Swap: 0k total, 0k used, 0k free

PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
```

### Основные поля

#### Общая информация

* **up** — время непрерывной работы системы (uptime).
* **users** — количество вошедших пользователей.
* **load average** — средняя нагрузка на систему за последние **1, 5 и 15 минут**.

#### Задачи (Tasks)

* **total** — всего процессов.
* **running** — выполняются.
* **sleeping** — ожидают выполнения.
* **stopped** — остановлены.
* **zombie** — процессы-зомби.

#### Использование CPU

* **us** — время, затраченное пользовательскими процессами.
* **sy** — время, затраченное ядром.
* **id** — процессор простаивает.
* **wa** — ожидание операций ввода-вывода (I/O).

#### Использование памяти

* **Mem** — использование оперативной памяти.
* **Swap** — использование раздела подкачки.

#### Список процессов

| Поле        | Описание                           |
| ----------- | ---------------------------------- |
| **PID**     | Идентификатор процесса.            |
| **USER**    | Владелец процесса.                 |
| **%CPU**    | Использование процессора.          |
| **%MEM**    | Использование оперативной памяти.  |
| **TIME+**   | Общее процессорное время процесса. |
| **COMMAND** | Имя процесса или команда запуска.  |

> **Примечание:** `top` обновляет информацию в режиме реального времени. Для выхода нажмите **q**. В современных системах также популярна утилита `htop`, которая предоставляет более удобный интерактивный интерфейс.



# Дамп сетевого трафика

Для перехвата и анализа сетевого трафика используется утилита `tcpdump`.

## Просмотр текстового трафика

Чтобы перехватывать трафик на порту `12345` и отображать его в виде ASCII:

```bash id="h5m2m5"
sudo tcpdump -i any -A port 12345
```

### Основные параметры

| Параметр       | Описание                                                                         |
| -------------- | -------------------------------------------------------------------------------- |
| **-i any**     | Прослушивать все сетевые интерфейсы.                                             |
| **-A**         | Отображать содержимое пакетов в формате ASCII (удобно для текстовых протоколов). |
| **port 12345** | Перехватывать трафик указанного порта.                                           |

Вместо `port` можно использовать:

* `host <IP>` — трафик конкретного хоста.
* `host <IP> and port <PORT>` — трафик определенного хоста и порта.
* `-n` — не преобразовывать IP-адреса и номера портов в имена (ускоряет вывод).

---

## Просмотр бинарного трафика

Если передаются бинарные данные, используйте режим `-X`:

```bash id="x4rzmx"
sudo tcpdump -i any -X port 12345
```

### Основные параметры

| Параметр | Описание                                                             |
| -------- | -------------------------------------------------------------------- |
| **-X**   | Выводить данные одновременно в шестнадцатеричном (Hex) и ASCII-виде. |

---

## Что содержит вывод

Каждый пакет состоит из двух частей:

1. **Заголовки** (IP, TCP/UDP и др.) — информация о маршрутизации и соединении.
2. **Полезная нагрузка (Payload)** — передаваемые данные.

Например, если клиент отправил строку `123`, то в конце дампа можно увидеть ее в ASCII и в шестнадцатеричном виде:

```text id="edbcbw"
0x0030: ... 3132 330d 0a ...
```

Здесь:

* `31` → `1`
* `32` → `2`
* `33` → `3`
* `0d 0a` → символы перевода строки (`\r\n`).

> **Примечание:** Для длительного анализа трафика удобнее сохранять его в файл (`tcpdump -w capture.pcap`) и затем открывать в Wireshark.
